Support

Seal is made by one person. If something is wrong or unclear, he wants to know.

What you need

  • An iPhone with Face ID, on iOS 17 or later.
  • For a Ledger: the Ledger with its OpenPGP app, a USB-C cable, and an iPhone with a USB-C port. You don’t need one.
  • For the session lock and for signing commits: a Mac, with the same Apple Account as the phone so the clipboard is shared, and the Mac side, Seal for Mac, a Claude Code plugin you install in one step.

Quick answers

Where are my files?

A file sealed for a vault is kept on this iPhone, in Seal’s own space: not in iCloud Drive and not in the Files app. It stays sealed on the disk. If iCloud Backup is on, it travels in your phone’s backup, still sealed. Deleting Seal deletes the kept files; files you shared or saved elsewhere stay where you put them. More in How it works.

I ticked two keys. Do I need both to open the file?

No. Each ticked key opens the file on its own. That way, losing one key doesn’t lose the file.

What if I lose my iPhone?

The phone’s key goes with it: it can’t be copied, by design. Files sealed for another key you own, such as a Ledger or a backup key, still open with that key. That’s why Seal suggests a second key for anything you must keep.

I set up Face ID again, and my key stopped working

iOS retires keys tied to the old Face ID, so this iPhone’s key stops working. Seal says so, and you can make a new one. Files sealed only for the old key can’t be opened.

A file didn’t ask for Face ID

Seal reads who a file is for before anything is opened. A file that isn’t for any key on this iPhone says so before asking for anything, so nobody gets a Face ID prompt for a file they can’t open. See Open a sealed file.

Does someone need Seal to open what I send?

Not always. A file sealed for their key opens with Seal or with gpg on a computer. A file locked with a passphrase opens with gpg 2.3 or newer, or with Seal. See Swap keys with someone.

The Ledger’s PIN: how many tries?

Three. The OpenPGP PIN is not the PIN that unlocks the Ledger; it goes to the card and nowhere else. Three wrong tries and the card locks. The Card page shows how many tries are left.

Which hardware keys work?

A Ledger with its OpenPGP app works today. YubiKey and other OpenPGP cards are planned.

Does Seal send anything anywhere?

No. Seal has no account, no analytics and no network code. See Privacy.

Contact

Email redthoroughbreds@gmail.com. You’ll hear back from Seth, who makes the app. It helps to include:

  • your iPhone model and its iOS version, and Seal’s version (More, under About);
  • whether a Ledger or a Mac was part of it;
  • what you did and what you saw. A screenshot is great.

Never send a PIN, a passphrase, or a file you’ve opened. None of them is needed to help you. A screenshot of a screen with an opened file on it shows what’s in the file, so leave those out too.
