Questions

Short answers to what people ask first.

Where are my files?

A file sealed for a vault is kept on this iPhone, in Seal’s own space: not in iCloud Drive and not in the Files app. It stays sealed on the disk, and the disk keeps it unreadable while the phone is locked. If iCloud Backup is on, it travels in your phone’s backup, still sealed. Deleting Seal deletes the kept files. Files you shared or saved elsewhere stay where you put them.

I ticked two keys. Do I need both to open the file?

No. Each ticked key opens the file on its own. That way, losing one key doesn’t lose the file.

What if I lose my iPhone?

The phone’s key goes with it: it can’t be copied, by design. Files sealed for another key you own, such as a Ledger or a backup key, still open with that key. That’s why Seal suggests a second key for anything you must keep.

What if I set up Face ID again?

iOS retires keys tied to the old Face ID, so this iPhone’s key stops working. Seal says so, and you can make a new one. Files sealed only for the old key can’t be opened.

Does Seal send anything anywhere?

No. Seal has no account, no analytics and no network code. It reads and writes only what you hand it.

Does someone need Seal to open what I send?

Not always. A file sealed for their key opens with Seal or with gpg on a computer. A file locked with a passphrase opens with gpg 2.3 or newer, or with Seal.

What can someone see when I’m not looking?

When Seal isn’t in front (the app switcher, Control Center), it shows a plain cover instead of what was open. Leaving the app closes any opened file.

Which hardware keys work?

A Ledger with its OpenPGP app works today. YubiKey and other OpenPGP cards are planned.
